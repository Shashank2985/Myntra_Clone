# 🛍️ Myntra Clone (Frontend)

A simple, responsive clone of the Myntra homepage using HTML and CSS. This project was built for learning and practicing frontend web development fundamentals including layout design, CSS styling, and responsive behavior.

## 🚀 Features

- Fully static clone of Myntra's homepage
- Responsive layout using Flexbox
- Custom navigation bar with hover effects
- Search bar and action icons (Profile, Wishlist, Bag)
- Banner section for promotions
- Category-wise product display
- Structured footer with links
